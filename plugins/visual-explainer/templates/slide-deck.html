API Gateway Redesign

From one proxy process to edge routing

01

The problem

Every request waits on one process.

The new request path skips the origin on a cache hit

Hits return from the edge in ~8 ms. Only misses reach the API.

Before

Monolith proxy

  • In-memory rate limits per instance
  • Synchronous JWT check: +40 ms
  • No circuit breaker

After

Edge native

  • Distributed rate limits
  • Cached keys: +2 ms
  • Automatic circuit breakers
